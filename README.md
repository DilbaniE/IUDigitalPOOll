# 💻 Sistema de Gestión de Empresas y Empleados

## 📌 Descripción

Este proyecto fue desarrollado en **Java** y permite gestionar **empresas y empleados** mediante un menú interactivo utilizando **JOptionPane**.

El sistema permite:

- 🏢 Registrar empresas  
- 👨‍💼 Registrar empleados  
- 🔍 Buscar empleados por documento  
- 📋 Listar empleados  
- 💰 Calcular sueldo según horas trabajadas  
- 📊 Contar empleados por empresa  

---

# 📂 Estructura del Proyecto

El proyecto está organizado en paquetes para separar responsabilidades.

### 📦 modelos
Contiene las clases del sistema:

- 👤 `Empleado` (clase abstracta)
- 👨‍💻 `Desarrollador`
- 🧑‍💼 `Admin`
- 📊 `GestorProyectos`
- 🏢 `Empresa`

---

### ⚙️ operaciones

Contiene las interfaces y sus implementaciones.

**Interfaces**

- `IOperacionEmpleado`
- `IOperacionEmpresa`

**Implementaciones**

- `OperacionEmpleado`
- `OperacionEmpresa`

Estas clases gestionan la lógica del sistema utilizando **ArrayList** para almacenar los datos.

---

# 🖥 Menú del Sistema

El programa funciona mediante un menú con **JOptionPane** que permite:

1️⃣ Registrar empresa  
2️⃣ Listar empresas  
3️⃣ Registrar empleado  
4️⃣ Listar empleados  
5️⃣ Buscar empleado por documento  
6️⃣ Calcular sueldo  
7️⃣ Contar empleados por empresa  
8️⃣ Salir
